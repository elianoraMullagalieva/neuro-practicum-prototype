# Нейро-практикум — локальный прототип

Открой `index.html` в браузере. Это локальный конверсионный прототип для трафика из Reels и рекламы; Figma и реальный сайт не изменялись.

## Что работает

- адаптивный лендинг;
- якорная навигация;
- FAQ-аккордеон;
- визуальный выбор тарифа без подключения оплаты;
- варианты заметки в hero для `?source=reels` и `?source=ads`.

## До публикации

Нужно подтвердить формат пяти работ, правила AI-кредитов, точный формат поддержки Эли, условия оплаты/возврата и подключить реальную форму/оплату с аналитикой.

`assets/reference/` хранит четыре сгенерированных референса, по которым собрана визуальная система.
