# Нейро-практикум — локальный прототип

Открой `index.html` в браузере. Это локальный конверсионный прототип для трафика из Reels и рекламы; Figma и реальный сайт не изменялись.

## Что работает

- адаптивный лендинг;
- первый экран по Figma: светлая навигация, CTA и бесконечная лента проектов;
- лента плавно движется справа налево, останавливается при наведении и отключает движение при системной настройке «уменьшить анимацию»;
- после hero — scroll-scrubbed pinned sequence: слова «Стратегия → … → Монтаж» появляются в рассеянной композиции, проходят через постеры и собираются в программу;
- якорная навигация;
- FAQ-аккордеон;
- визуальный выбор тарифа без подключения оплаты;
- варианты заметки в hero для `?source=reels` и `?source=ads`.

## Замена фото на видео

В `index.html` замени соответствующий `<img>` внутри `.work-card` на:

```html
<video autoplay muted loop playsinline preload="metadata" poster="assets/hero/work-01.png">
  <source src="assets/hero/work-01.mp4" type="video/mp4" />
</video>
```

Стили уже одинаково обрабатывают изображения и видео; направление ленты и адаптивная высота сохранятся.

## Как называется новая анимация

- **Pinned scroll / scroll pinning** — экран временно закреплён во время прокрутки.
- **Scroll scrubbing** — положение скролла напрямую управляет таймлайном: можно листать и вперёд, и назад.
- **Scatter-to-stack** — слова сначала разбросаны, затем собираются в последовательность.
- **Staggered reveal** — элементы появляются с небольшой задержкой, а не одним кадром.

Таймлайн работает на локальной копии Anime.js: `assets/vendor/anime.min.js`, поэтому не зависит от CDN.
